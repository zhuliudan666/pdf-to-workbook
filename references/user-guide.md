# 做题本制作手册

把 PDF（或书页照片）变成能直接打印手写的做题本：每题切下来、下面留白、加页眉章节页目录书签。

> 这份只管怎么用。想看内部原理，去 `SKILL.md`。

---

## 1. 三步做完

```powershell
# 把这个 skill 放在哪，就填哪；PY 指向装好依赖的解释器
$SKILL = "C:\path\to\pdf-to-workbook"
$PY    = "python"

& $PY "$SKILL\scripts\intake.py" "D:\书\book.pdf" --out "D:\书\out"                        # ① 出计划
& $PY "$SKILL\scripts\build.py"  "D:\书\book.pdf" "D:\书\out\intake.yaml" "D:\书\out"      # ② 跑全流程
```

```
book.pdf ─① 出计划─→ 问你 2~3 句 ─→ intake.yaml        （这本书的配置）
                                        │
           ② 8 步全自动 ────────────────┘
              ↓
        做题本.pdf    ←── 打印
        校对单.pdf    ←── 五分钟翻一遍
        制作说明.md  ←── 当时做了哪些判断、哪些没验到
```

**① 只问你测不出来的**：做哪些页、留白多少、纸型。页数、是不是扫描件、单双栏，它自己量。

| 退出码 | 意思 | 你做什么 |
| --- | --- | --- |
| `0` | 计划好了 | 看一眼 `out\intake.md`，往下跑 |
| `3` | 缺一个决定 | 回 `intake.md` 里的问题（最多三个） |
| `4` | 这本做不了 | 停。看它指出的原因 |

**② 中间不用管**：体检 → 切题 → 裁图 → 质检 → 结构校验 → 校对单 → 拼版 → 验收。
扫描件自动插 OCR，电子版直接读坐标。

**耗时**：电子版几秒；扫描件约 5 秒/页（106 页 ≈ 9 分钟），有缓存，重跑 20 秒。

> **第一次先跑 3 页**：`--say "先跑3页"`。切点对了再放开整本，别一上来等十分钟。

## 2. 先确认这本能做

三条检查，任何一条不过就别跑：

| 检查 | 不过怎么办 |
| --- | --- |
| **每道题有题号吗** | 没有 → 做不了，只能手工给范围或走照片路线逐页指定 |
| **是单栏吗** | 双栏 → 做不了（合成样张实测 36 题只认出 18 道）。先裁成单栏再给 |
| **PDF 能打开吗** | 加密/DRM → 打不开；Word/PPT → 先另存为 PDF |

能做的六类（右边是实测成品）：

| 素材 | 你怎么说 | 实测 |
| --- | --- | --- |
| 整本练习册 | 「整本做成做题本」 | 某数三习题册 106 页 → **720 题 / 220 页 / 6.1MB** |
| 套卷、真题合订 | 「这份卷子做一遍」 | 数三 2010–2026 合订 52 页 → **385 题 / 120 页** |
| 单章、单讲 | 「只做第 18 讲」「只要 60–75 页」 | 某数三习题册 p63–67 → 15 题 |
| 讲义章末课后题 | 「把每章课后题做成做题本」 | 某运筹学教材 45 页 → **173 题 / 70 页** |
| 讲义里的例题 | 「把例题做成做题本」 | 某线代讲义 69 例 / 6 章 |
| 手机拍的书页 | 发照片 + 告诉我是哪几题 | 单页流水线，**没有校对单，必须自己看图** |

**还能做的其他毛病**：双色套印（改 `image.mode: gray` 保留灰度，彩色还原不了）、
原书手写笔迹（去不掉，会一起切进图里）、一本书里版式中途变了（拆成几个 PDF 分别做）。

**还没做的**：按题号挑题（错题本）、答案册、跨书合并。要哪个说一声。

## 3. 你只需要定三件事

### 做哪些页

| 你说 | 结果 |
| --- | --- |
| 全书 / 整本 | 全部页 |
| 先试几页 | 前 3 页 |
| 只做第 18 讲 / 只要 60–75 页 | 页码范围（`60-75`、`1-9,12` 都行） |
| 讲义只做课后题 / 只做例题 | 不用给页码，程序自己圈 |

### 一页排几道题

按「每页几道」定，毫米是算出来的。

| 档位 | 选填 | 大题 | 适合 |
| --- | --- | --- | --- |
| **紧凑** | 5 道/页 | 4 道/页 | 只写答案、一行算式 |
| **标准**（默认） | 4 道/页 | 3 道/页 | 能写下主要推导 |
| **宽裕** | 3 道/页 | 2 道/页 | 完整证明、要画图、反复涂改 |

参考留白：紧凑 12/25/45mm、标准 18/33/62mm、宽裕 25/45/95mm（选填/解答）。

### 纸型和清晰度

A4 单面（默认）/ A4 双面装订（左边多留 15mm）/ B5 便携。
留白可选纯白、淡中线、淡点阵。

分辨率够时清晰度**不用管**。只有 dpi < 170 或手机照片才会弹「清晰度」卡片，两个选项直接带预估时间：

| 选项 | 大概多久 | 说明 |
| --- | --- | --- |
| 位图裁切（默认） | 几分钟 | 全自动，原样保留字形，按低 dpi 印会有点发虚 |
| 矢量重排 | 按题数 × 30–60 秒，整本常以小时计 | 印刷级清晰，但由 agent 逐题看图转写、再逐题对照原图核 |

时间是粗估（扫描件按每页约 5 题算），实际题数以切出来的为准。选了矢量**不是一键切换**：
脚本先照常出位图裁片，再生成 `items.json` 模板，agent 逐题填写后跑 `reflow.py` 出矢量成品和校对单
（见 `SKILL.md`「选了矢量重排，agent 怎么接手」）。有文本层的 PDF 选它会被自动改回位图 400dpi
——源头本来就是矢量，转写只会引入识别错误。

## 4. 交付前看三样东西

### 校对单.pdf

全自动切题一定有百分之一二出错，这几分钟省不掉。已按风险排好，不用从头翻：

| 区 | 怎么看 |
| --- | --- |
| **红框** | 逐题看。切点可疑、题号异常、跨页接续的都在这 |
| 黄框 | 快速扫，看有没有缺半截的 |
| 灰框 | 只看**有没有缺题**，别看切点 |

判断标准只有一条：**这道题的内容完整吗**。少一行、多吃进下一题的开头，都算错。

### qa.csv（这张表有个反直觉的地方）

| 标记 | 要不要修 |
| --- | --- |
| **右贴边** | **必须修**。字被裁掉了 |
| **窄缝**（<3.5pt） | **要目检**。可能削掉下标或分数线的边 |
| **切穿** | **不用管**。相邻两题本来就没空白、跨页续文切在页边界，必然切穿 |

三本实测：右贴边 **全 0**；切穿 75 条逐一看过，内容全完整；窄缝 18 处也都在。

所以读法是：**先看右贴边是不是 0，再看窄缝有几处，切穿的条数直接忽略。**

### 制作说明.md

随成品一起给的还有一份说明：这本书分成几册、哪几页按卷标题拆过、补了哪几条题号正则、
页眉用的什么书名，哪些项是按默认走的，以及**哪些没验到**（搜不到题干的题、qa 有标片数、
`accept.json` 的 `warnings`）。换台机器或隔半年再看，不用重新回忆当时为什么这么切。

### 最后七条自检

1. 页眉写的是**这本**书吗？翻到第 100 页看，别只看第一页
2. 目录随便挑三条，页码对得上正文吗
3. 目录里的章数 = 原书「※命题点」横幅数？**少一章不报任何错**
4. 随便翻三页，答题区够写吗、有没有哪题顶到页脚
5. 先只打 2 页，确认不糊再整本打
6. `accept.json` 的 `warnings` 里有没有「未覆盖」的闸？**验收通过 ≠ 都查过**，空跑的闸要补跑或在交付时说清楚
7. `制作说明.md` 的「没验到」一节有没有需要补跑的项（例如某几题搜不到题干）

## 5. 不对就查这张表

改 `intake.yaml`，然后重跑（见下）。

| 症状 | 改哪 |
| --- | --- |
| 页眉印着别的书名 | 清空 `header.book`，让它从原书页眉读 |
| 一题都没切出来 | 看 `probe.md` 的命中表，往 `question_patterns` 加一条 |
| 某页整页题没了 | 调 `ocr.strip_x0`（40→25） |
| 题号被切掉半截（「1.［2010」变「010」） | `content_box` 要和 `ocr.strip_x0` **一起**改成 24 |
| 题图里带着「解：」和答案 | `cut_stop_patterns` 加一条，匹配「解：」「答：」开头的行 |
| 每章都报题号重复 | 配置里加 `chapters:`（哪页是哪章），`find_exercises.py --patch` 会自动写 |
| 切出几十道「定理 1.1」 | 讲义没圈范围，先跑 `find_exercises.py` |
| 留白不够写 | 换「宽裕」档，或调低 `answer_gap_floor_by_section` |
| 一道小题拉开半页 | 调低 `answer_gap_cap_by_section` |
| 一页只有 1–2 道、很空 | 调 `min_scale`（0.8→0.7） |
| 打印发虚 | 提高 `paper.dpi`（有文本层可到 400），或走矢量重排 |
| 文件太大 | 降到 300dpi；`gap_style: blank` |
| 题图底部有黑线或页码 | 往 `ignore_patterns` 加一条 |
| 双栏切得乱七八糟 | 双栏做不了，先裁成单栏 |

### 改完重跑哪几步

流水线是 **切题 → 裁图 → 拼版** 三级链，只重跑下游：

| 改的是 | 重跑 |
| --- | --- |
| 题号正则、`chapters` | 切题 → 裁图 → 拼版 |
| `strip_x0`（条带左沿） | 同上，**会整本重识别**（约 9 分钟） |
| `strip_x1` / `strip_dpi` | 同上，**并且先清 `ocr/`**——否则改了等于没改 |
| 留白、配额、页眉 | **只重跑拼版**，秒级 |

嫌麻烦就直接重跑 `build.py`，有缓存，扫描件也就 20 秒。

清缓存别自己删目录：

```powershell
& $PY "$SKILL\tools\clean.py" "D:\书\out"          # 清题图和临时文件
& $PY "$SKILL\tools\clean.py" "D:\书\out" --ocr    # 连 OCR 缓存一起清
& $PY "$SKILL\tools\clean.py" "D:\书\out" --dry    # 只报会删什么，不动手
```

## 6. 参数速查

只列你真会去改的，全部字段见 `config.yaml`。

```yaml
pages: "60-75"                  # 空 = 全书
page_quota: {选择题: 4, 填空题: 4, 解答题: 3, 证明题: 3}
answer_gap_floor_by_section: {选择题: 14, 填空题: 26, 解答题: 32, 证明题: 32}
answer_gap_cap_by_section:   {选择题: 40, 填空题: 60, 解答题: 130, 证明题: 130}
min_scale: 0.8                  # 题图最多缩到 80%
gap_style: blank                # blank | line | dots
text_layer: true                # 成品可搜索（题图上盖不可见文字）
text_layer_source: auto         # auto | native | ocr | off；扫描件走 ocr 要多跑一遍整页 OCR
paper: {size: A4, dpi: 300, margin_left: 66}    # 双面装订 margin_left 改 81
header: {book: "", title: "", show_source_page: true}
ocr: {strip_x0: 24}             # 要和 content_box: [24, 548] 一起改
```

## 7. 让下一本更快

一本书做完之后跑一条，把它变成预案。**省这一步，下一本同类书还是从零开始。**

```powershell
# 第一次遇到的类型
& $PY "$SKILL\tools\learn.py" "D:\书\out" --cfg "D:\书\out\intake.yaml" --id 新类型 --label "一句话"

# 同类书第 2 本（不要另立门户，两个预案会互相抢）
& $PY "$SKILL\tools\learn.py" "D:\书\out" --cfg "D:\书\out\intake.yaml" --merge bank-book

# 先看会写出什么
& $PY "$SKILL\tools\learn.py" "D:\书\out" --cfg "D:\书\out\intake.yaml" --id xxx --dry
```

它会读回这次的真实结果、自动定判据松紧（拿 7 本基线试，谁被误认就收窄），
并且**只带走这一类通用的配置**——页眉书名、页段、条带几何都是"这本书的账"，抄到下本上就是事故。

现有预案 6 类：习题册 / 真题卷 / 例题册 / 讲义 / 手机照片，另一类是双栏（认出来是为了拦下）。

## 附：其他命令

```powershell
& $PY "$SKILL\scripts\classify.py" 书.pdf --why          # 先看这是什么素材，不跑流水线
& $PY "$SKILL\scripts\find_exercises.py" 讲义.pdf --patch 输出目录\intake.yaml   # 讲义圈课后题
& $PY "$SKILL\scripts\split_volumes.py" 书.pdf --out 书_分册.pdf --patch 输出目录\intake.yaml --record 输出目录\split.json  # 多套合订按卷拆页
& $PY "$SKILL\scripts\photo_pipeline.py" --src 照片.jpg --prefix 18 --out 出.pdf  # 单页照片
& $PY "$SKILL\scripts\selfcheck.py" 书.pdf 输出目录 配置.yaml                     # 切点自检
& $PY "$SKILL\scripts\diagnose.py" --check 输出目录\selfcheck.json               # 诊断：该改哪一行
& $PY "$SKILL\scripts\reflow.py" items.json -o 做题本.pdf                       # 矢量重排（已转写的 LaTeX → PDF）
& $PY "$SKILL\tools\render_preview.py" 输出目录\做题本.pdf 预览目录 110           # 转 PNG 肉眼核对
```

**几套卷 / 几年真题合订**：每套题号都从 1 重排，不分册会被判重号删掉一半。扫描件的目录常是图片，
`intake.py` 认不出分册时会在回执里提示；卷次交界和上一套末题挤在同一页时，
先跑 `split_volumes.py`（按卷标题拆页、丢目录页、写好 `chapters`），
再拿「书_分册.pdf」当输入跑 build。认不出卷名它会停，可用 `--titles` 手工给。

**原理一句话**：默认把每道题当一张图裁下来，只重新分配留白和页面骨架。原书的排版本身就是最好的排版；
只有分辨率撑不住打印时，才换「转 LaTeX + 矢量重排」——那条路能拿到印刷级清晰度，但会引入"识别错了还看起来完全正常"这种最难发现的失败。
