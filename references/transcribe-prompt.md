# 转写提示词（题目图 → items.json）

矢量重排这条路只有一个环节需要模型：**读图转 LaTeX**。它也是整条链上唯一
「错了但看起来完全正常」的环节，所以提示词的目标不是「写得漂亮」，是**把不确定的地方说出来**。

用法：每张题图单独发一次（不要一次塞十张，分辨率掉下去识别率跟着掉），
下面这段整段作为指令，图作为附件。

---

## 提示词正文（可直接复制）

```text
你是考研数学习题的转写员。我给你一张从扫描件裁下来的题图，你把里面的题目
转写成 JSON，交给排版程序直接渲染。只输出 JSON，不要解释、不要代码块标记。

输出格式（一个数组）：
[
  {"no": "18.3",
   "kind": "fill",
   "stem": "设 $L$ 为取正向的圆 $x^2+y^2=a^2$，$a>0$，则曲线积分",
   "disp": "$\\displaystyle \\oint_L \\frac{2xy}{x^2+y^2}\\,\\mathrm{d}s=\\underline{\\qquad}$",
   "subs": [],
   "uncertain": ["被积函数分子原图偏糊，读作 $2xy$，也可能是 $2x y^2$"]}
]

字段规则：
- no：题号，原样照抄（18.3 / 7 / (2) 都行），别自己重编。
- kind：choice（选择）| fill（填空）| solve（解答/证明）。看不出来按 fill。
- stem：题干。中文保持原样，公式用 $...$ 包起来，不要在中文里用 \text{}。
- disp：独立成行、居中的那部分（长公式、积分式、矩阵、带下划线的填空线）。
  填空线写成 \underline{\qquad}。没有就省略这个字段。
- subs：分小题，一问一条字符串，如 "(1) 证明 …"、"(2) 求 …"；选项 (A)(B)(C)(D)
  也是一行一条放在这里。没有就写 []。
- uncertain：**这一项最重要**。凡是你不确定的，一条一句写清楚：哪个符号、
  你读成了什么、还可能是什么。看不清就写"看不清"，不要猜一个填上去当没事。

硬性要求：
1. 只转写图上真实存在的内容。图上没有的条件、没有的选项，一个都不许补。
2. 上下标、积分上下限、区间端点、正负号、绝对值、转置 T、伴随 * —— 逐个确认，
   这些是最容易丢且最难被发现的地方。
3. 中文标点保留（，。；：），不要换成英文逗号；数学里的逗号用 , 。
4. 希腊字母用命令：\alpha \beta \Gamma \Sigma \varphi；π 是 \pi，不是 \mathrm{\pi}。
5. 分式用 \frac{}{}，多重积分用 \iint \iiint，曲线/曲面积分用 \oint_L \iint_\Sigma。
6. 一道题都认不出来、或整张图糊到不可读，就输出 []，并在旁边用一句话说明原因。

输出前自查一遍：
- 题干里的每个数字，图上都有吗？
- 每个上标下标都转了吗？
- 有没有哪一处我其实是猜的？有就搬进 uncertain。
```

---

## 为什么这么写

| 要求 | 针对的失败 |
| --- | --- |
| `uncertain` 必填、允许写"看不清" | 模型的默认行为是补全。给个出口，它才肯说不知道 |
| 只输出 JSON、不要代码块 | 代码块标记会让 `json.load` 直接抛错，每次都得手工剥 |
| 禁止补条件 | 缺条件的题看起来最正常，做题做到一半才发现无解 |
| 上下标单独点名 | OCR/转写丢上标是高频且静默的，`x^2` 变 `x2` 照样能排版 |
| 一次一张图 | 多图同发时分辨率被摊薄，小字号的上标最先消失 |

## 转完之后必须做的两件事

1. **把 `src_image` 补进每题**（就是这张图的路径）。没有它，校对单只能显示转写结果，
   无法左右对照——而"对照原图"是这条路唯一有效的核对方式。
2. **跑 `reflow.py`**，它会因为有 `uncertain` 或 `src_image` 自动生成 `_校对单.pdf`。
   校对单里红框逐题核，核完再交付。**没有任何 uncertain 不等于没有错**，
   它只等于模型这次没说。公式密集的题仍然要扫一眼原图。

## 已知边界

- KaTeX 不支持的宏会退化成红字或原文，长任务里先在 `reflow.py` 渲染 2 道题试水。
- 矩阵、分段函数的大括号在 KaTeX 里用 `\begin{cases}` / `\begin{pmatrix}`，
  转写时就要写成这两种环境，别写 `\left\{ \begin{array}`。
- 离线环境要先把 KaTeX 的 css/js/字体下到本地，否则公式全部退化成 `$...$` 文本。
